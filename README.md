# DTX Studio

DTXManiaNX 向けの、ローカルファーストな Web 譜面エディタ。
原曲を聴く・区間をループする・譜面を編集する作業を、同じ時間軸で行います。

## 使い始める

1. **開く**で曲の DTX と音源をフォルダまたは ZIP から読み込みます。
2. **＋ 音声**で参照する原曲を選び、BPM と原曲オフセットを調整します。
3. グリッドをクリックして配置。選択ツールで範囲選択・ドラッグ移動できます。
4. A/B ループ・低速再生で確認し、**DTX 書き出し**から素材付き ZIP を保存します。
5. 実際の DTXManiaNX でも再生とタイミングを最終確認してください。

初回はオリジナルの練習譜面と Standard ドラムキットが開きます。
内蔵 Standard / Electronic / Jazz は FluidR3Mono の GM percussion を MIDI レンダリングした音源です。
使うキットだけを取得し、書き出し ZIP にライセンスを含めます。
MIDI データそのものは音源ではありません。MIDI のインポート／エクスポートはノートとテンポの変換です。

## 編集・互換性

- HH、LC、RC、Ride を独立した NX チャンネルとして扱います。オープン HH、左足、左バス、タムも保持。
- コピー／切り取り／貼り付け、矩形選択、ドラッグ、グリッド整列、Undo/Redo、チップ検索、リソース置換。
- 持続する小節長、途中の BPM、BASEBPM、000–Z99 小節、01–ZZ 音源 ID。
- ギター／ベースの 5 フレット、BGM、SE、フィル、ミュート、画像・動画リソース。
- WAV 音量・パン・サイズ・ラベル・色、Creator パレットと表裏レーン割当。
- CP932 を標準とする DTX 書き出し、DTX / GDA / G2D / BMS / BME / MIDI 読み込み。
- 元データを壊すおそれのある分岐・再定義や未対応の高度な旧形式は読み取り専用にし、原文を保存します。

詳しい比較と検証範囲は [Creator 互換性](documentation/creator-parity.md) を参照してください。
全機能の実機互換や全ての旧ファイルが無損失に変換できることは保証しません。

## BPM・拍子変化と開始位置

- **原曲の先頭オフセット**は曲全体の位置合わせです。`音声の秒数 = 譜面の秒数 + オフセット`。例えば `+0.25` は原曲の0.25秒を譜面の0拍に合わせます。**これだけでは途中のBPM変化は補正できません。**
- **BPM・拍を自動解析 / 拍アンカー**からローカル音声の候補を解析できます。半速・倍速・裏拍の可能性と区間候補を表示します。結果は自動適用されません。
- 確認済みの「譜面の拍」と「原曲の秒数」を2点以上指定すると、各区間のBPMを計算します。最初は拍0。拍は四分音符単位です。例：拍0が0.25秒、拍4が2.25秒なら120 BPM、拍8が約3.583333秒なら次の区間は180 BPMです。
- 試聴・確認チェックの後に適用すると、既存テンポマップと開始位置を置き換えます。小節長・ノートはそのままです。候補の開始拍は必ずしも曲の最初の拍・小節頭ではありません。
- 変拍子は小節編集で長さを設定します。DTXの小節長変更は次の変更まで持続します。自動BPM解析は拍子を断定しません。長い曲・スイング・弱い打音では手動確認が必要です。

解析対象はローカル音声のみ。YouTube音声抽出やAIへの音声送信は行いません。解析範囲・キャンセルなどは [BPM解析の仕様と制限](docs/BEAT-ANALYSIS.md) を参照してください。

## 電子ドラム・Web MIDI

**電子ドラム・MIDI 機器設定**から明示的に接続します。対応ブラウザ・HTTPS・入力権限が必要です。MIDIファイルの読み込みとは別機能です。

1. 入力ポートを選び、**機器ごと・モードごと**のプロファイルを作成します。同名機器や同じCHでも、別機器の入力を混ぜません。再接続後は割当を確認してください。
2. **機器＋モード＋CH（1〜16）＋ノート番号**で各打面を学習します。HHのbow/edgeなど複数打面を別々に登録できます。学習中は録音・試聴を抑止します。
3. ペダル状態でHHを切り替える機種は、ペダルCCも学習・校正します。打面とペダルのCHが違っても設定可能です。開閉反転、しきい値、ヒステリシス、古い状態の無効化に対応。DTXでは閉HH `11` / 開HH `18` を使用します。
4. 試聴で確認後、録音を有効にします。**正の入力遅延補正は記録位置を早めます**。原曲オフセットや譜面音の出力遅延とは別の設定です。

プロファイルはブラウザに保存しJSONで持ち運べます。汎用設定は特定メーカーの動作保証プリセットではありません。**物理機器の接続・実機固有のHH/CC挙動は未検証です。** 詳細は [Web MIDI入力ガイド](docs/MIDI-INPUT.md) を参照してください。

## ローカル保存

譜面と素材は IndexedDB に保存します。取り込んだ曲や音源はサーバーへアップロードしません。
自動保存はこのブラウザ・このサイトに限定されます。ブラウザのデータ削除や容量制限に備え、プロジェクト ZIP をバックアップしてください。
曲フォルダから音源だけを抽出することもできます。素材の利用権・再配布権は元のライセンスに従ってください。

## YouTube

ユーザーが URL を読み込んだときだけ公式 IFrame Player API を使います。動画の取得・音声抽出・ダウンロードは行いません。
ネットワーク、埋め込み可否、広告・バッファリング、API の時間精度の影響を受けるため、厳密な耳コピには権利のあるローカル音源を推奨します。
ローカル参照音源の低速再生はピッチも変わります。

## OpenRouter

設定で API キーとモデル ID を入力します。保存は明示的に選択した場合だけ localStorage、保存しない場合は現在のタブ内だけです。
キーは OpenRouter への認証にだけ使用し、GitHub、DTX、プロジェクト ZIP に含みません。
同じサイト上の JavaScript から参照可能なため、共有端末では保存しないでください。

- 難易度生成は元ノート ID・拍・レーン・テンポ等を匿名化して送信し、元譜面を保持した候補として表示します。
- 曲情報検索は曲名・アーティスト・参照 URL を送信し、OpenRouter の検索ツールを使います。検索は追加料金が発生する場合があります。
- 音声ファイルは AI に送信しません。モデル出力は検証し、出典と候補を確認してから採用します。
- 実際のモデル呼び出しには利用者の API キーと残高が必要です。自動テストはモックであり、すべてのモデルの応答品質・実料金・待ち時間を保証しません。

## 開発

```sh
npm ci
npm test
npm run dev
npm run build
```

Node.js 22 以上。GitHub Actions はテストと本番ビルドが成功した main だけを Pages に公開します。
静的ホスティング以外のサーバーやサービスアカウントは不要です。

## 音源コレクションとパレット

左の **音源コレクション** から、現在の WAV バンクを名前・タグ・分類付きでこのブラウザに保存し、別の曲に選んで追加できます。衝突しないパスと新しい WAV ID に割り当て、元のライセンス・出典ファイルを保持します。**パレット設定** はお気に入りの表示と、パレット・レーン割当の名前付きプリセットを管理します。ID を参照するため、別の曲への適用時は対応を確認してください。

ギター／ベースでは開始ノートを選び **ホールド区間を設定** から終端の拍を指定できます。NX の仕様上、OPEN での開始や区間内・終端の別演奏ノートは認めません。
